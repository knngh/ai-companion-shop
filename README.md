# 心伴 · AI 陪伴与品质生活

主打 **AI 陪伴主题** 的导购网站，引导用户购买手办、小众好物与成人用品（成人专区需年龄确认）。

## 功能

- **首页**：品牌与 Slogan，突出 AI 陪伴 + 好物
- **AI 陪伴**：对话浮窗，模拟 AI 根据关键词推荐「手办」「小众好物」「成人用品」
- **手办周边**：手办、景品、盲盒、立牌等商品展示与加入购物车
- **小众好物**：香薰、手账、文创、解压玩具等
- **成人专区**：需勾选「已满 18 周岁」才能进入，展示情趣用品等（文案与展示合规）
- **购物车**：侧边栏展示、删除、合计与结算入口（结算为演示）

## 运行方式

本地直接打开 `index.html` 即可：

```bash
cd ai-companion-shop
open index.html
# 或
python3 -m http.server 8080
# 浏览器访问 http://localhost:8080
```

## 技术栈

- 纯静态：HTML + CSS + JavaScript
- 无构建、无后端，便于二次开发或对接 API
